AI-Powered Safe Street Crossing for the Visually Impaired

An intelligent robotics system that leverages computer vision and real-time object detection to help blind individuals navigate street crossings safely. Using MobileNet SSD and optical flow analysis, SafeCross provides haptic feedback to alert users of moving vehicles.

How It Works

A step-by-step breakdown of the SafeCross pipeline

📹
01

Camera Capture

USB camera captures live video feed at 25 FPS, providing continuous visual input of the street environment.

→
🔍
02

Object Detection

MobileNet SSD identifies objects in the frame with 0.3 confidence threshold, detecting vehicles, persons, bicycles, and more.

→
🌊
03

Motion Analysis

Lucas-Kanade optical flow (40 feature points) determines which detected objects are moving vs. static.

→
⚠️
04

Safety Decision

Algorithm checks if moving vehicles (bus, car, truck, motorbike) are in the critical zone (lower 60% of frame).

→
📊
05

Smoothed Output

SafetyHistory smooths decisions over 2-second window with 70% threshold to avoid false alerts.

→
📳
06

Haptic Feedback

Vibration motors provide tactile alerts: one pattern for "safe to cross", another for "do not cross".

def run_detection(net, frame):
    (h, w) = frame.shape[:2]
    blob = cv2.dnn.blobFromImage(
        cv2.resize(frame, (300,300)),
        0.007843, (300,300), 127.5
    )
    net.setInput(blob)
    detections = net.forward()
    result = []
    for i in range(int(detections.shape[2])):
        conf = detections[0, 0, i, 2]
        if conf > THRESHOLD:  # 0.3
            idx = int(detections[0, 0, i, 1])
            label = CLASSES[idx]
            box = detections[0, 0, i, 3:7] * np.array([w, h, w, h])
            (sx, sy, ex, ey) = box.astype("int")
            result.append((label, conf, (sx, sy, ex, ey)))
    return result

def decide_safety(moving_objs, target_h):
    for obj in moving_objs:
        label, bbox, _ = obj
        center = (bbox[1] + bbox[3]) / 2.0
        
        # Check if vehicle in critical zone (lower 60%)
        if label in {"bus", "car", "truck", "motorbike"} \
           and center > 0.6 * target_h:
            return False  # UNSAFE
    
    return True  # SAFE

class SafetyHistory:
    def get_smoothed_decision(self):
        if not self.history:
            return False
        ratio = self.history.count(True) / float(len(self.history))
        return ratio >= self.thresh  # 70% threshold

Hardware & Requirements

🔧 Hardware Components

  • Raspberry Pi 4 - Main processing unit
  • SD Card - For operating system storage
  • USB Camera - Real-time video capture
  • 2x Vibration Motors - Mini Vibration Motor Module with PCB Driver Board
  • Power Bank - Portable power supply

💻 Software Requirements

  • Python 3.11 - Programming language
  • OpenCV - Computer vision library
  • NumPy - Numerical computing
  • MobileNet SSD Model - .caffemodel weights
  • Deploy Prototxt - Model architecture definition

⚙️ Setup Guide

  1. Install Raspberry Pi OS on SD card and configure WiFi, username, and hostname
  2. Update the system: sudo apt update && sudo apt upgrade
  3. Install dependencies: pip install numpy opencv-python
  4. Download model files from the GitHub repository (.caffemodel and .prototxt)
  5. Connect hardware components: USB camera to Pi, vibration motors to GPIO pins 17 & 27
  6. Transfer project files to Raspberry Pi via SCP or USB
  7. Run the application: python main.py
  8. Optional: Configure autostart on boot for production use
